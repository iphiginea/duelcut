# Duel Cut

A movie ranking app that turns taste into head-to-head duels and builds a personal ranking from every pick.

**Live app:** https://iphiginea.github.io/duelcut/

## About

Duel Cut ranks movies by comparison instead of isolated scores. Each round presents two films; choose the one you liked more and the ranking updates from those decisions.

The idea is simple: choosing between two movies often says more about your taste than giving both of them the same star rating.

## Features

- Head-to-head movie comparisons
- Personal rankings that evolve with each choice
- Focused two-film decision interface
- Persistent taste history in the browser
